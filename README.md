## Description

Weather Diary is a console application for storing and analyzing weather data.

The application allows users to:

- add weather records
- delete records
- filter data by date
- filter data by temperature
- save and load data from JSON
- build temperature graphs using matplotlib

---

- JSON

- matplotlib
